# 501 户型编辑器

[打开在线编辑器](https://tiggerhat.github.io/floorplan-501/)

基于 [wy51ai/floorplan-3d](https://github.com/wy51ai/floorplan-3d) 的纯前端户型与装修工具，内置 501 空房模型。支持修改墙体、门窗、房间边界，以及家具布置和 3D 查看。无需登录，无后端服务。

## 编辑户型

### 门窗组件

进入“编辑户型”，点击画布上方 **门窗组件**，即可展开组件库。提供平开门、推拉门、普通窗、推拉窗、固定窗、落地窗和深窗台窗 7 种预设。选组件后在画布单击放置默认尺寸，也可以按住拖出所需宽度。

推拉门支持 2／3／4 扇、门高、门宽、方向和位置编辑，可复制、删除、撤销，并同步到 2D、3D 与 JSON 备份。窗户可以修改窗型、1–6 个分格、窗台和窗高；落地窗默认窗台为 0。深窗台窗是单面窗预设，转角飘窗可通过多扇窗拼接，现有户型不会自动重画。

旧版方案不包含窗型和推拉门参数时，会补齐默认值，保留原有墙线、位置与尺寸。

1. 点击顶部 **编辑户型**，或按 `E`。
2. 点击墙、窗、门，或在右侧“选择对象”中选取。
3. 在属性面板输入墙长、墙厚、门宽、窗宽、坐标或方向，点击 **应用尺寸**。窗户还能修改窗台高度、窗高。
4. 拖动橙色端点可伸缩，拖动对象可移动。方向键微调 10 mm，按住 Shift 微调 100 mm。
5. 用画布上方的 **画墙 / 画窗 / 画门 / 画房间** 按住拖出新对象。门窗从墙体上起笔时匹配墙的方向和厚度，与墙相交的部分会自动留洞。
6. 选择房间可编辑顶点坐标，或拖动顶点修改边界，面积随之更新。墙体侧移时可选“联动同线房间边界”。

可以复制、删除、撤销和重做。门可以切换铰链侧和开启方向。切到 **3D 场景** 会使用当前修改后的几何数据。

房间边界和墙窗位置可分别编辑。本工具不自动求解所有建筑连接关系；移动墙后请检查相邻墙角、门窗、房间边界。删除原有窗门会由其宿主墙补回墙面；若需要完整拆掉该位置，还需删除相应墙段。

## 保存与备份

- 每次完成编辑自动保存在当前浏览器本机，刷新后保留。
- 点击 **文件 → 导出方案 JSON** 或 **导出户型备份**，保存完整户型、家具和装修状态。
- 使用 **导入方案** 恢复备份或换设备继续编辑。非法几何数据会被拒绝，保留当前方案。
- 浏览器之间不会自动同步。清除网站数据、无痕窗口关闭后可能失去本机保存内容，请导出备份。
- 保留对旧版家具方案 JSON 的兼容；旧文件不含几何时，使用默认 501 户型。

## 本地运行

```bash
python3 -m http.server 8000
```

访问 `http://localhost:8000`。2D 无需外部服务；Three.js r160 已随项目提供，无需从第三方 CDN 加载。直接用文件协议打开 HTML 时，部分浏览器会限制 3D 模块，请使用 HTTP 服务或在线页面。

## 数据与精度

模型依据户型图像重建，单位 mm；局部墙线、门窗及房间面积为描摹推算。图中深色墙段与其他墙段的承重性质均待核实。默认层高 2800 mm，门高约 2100 mm；窗高和窗台高可编辑，窗顶不得超过默认层高。

“编辑户型”修改数字模型，不代表允许现场拆改。原项目的拆墙工具仍限制未经核实的墙段。模型不作为施工放线或结构鉴定依据。

## 开发

```bash
npm test
```

- `index.html`：2D/3D 渲染、家具交互、完整方案状态与本机保存。
- `geometry-core.js`：几何校验、编辑事务、房间边界联动、门窗洞口裁切，可在 Node 中测试。
- `geometry-editor.js`：页面表单、端点伸缩、对象移动、绘制和键盘操作。
- `geometry-editor.css`：编辑器与移动端适配。
- `tests/geometry.test.cjs`：12 项几何行为、组件与异常输入测试。
- `vendor/three/`：Three.js r160 及本项目所需的 addons。

GitHub Pages 从 `main` 分支根目录发布；GitHub Actions 对提交运行测试和脚本检查。
